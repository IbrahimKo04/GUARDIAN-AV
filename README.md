# GUARDIAN-AV

🚗 GAN-Based Adversarial Attacks on Autonomous Vehicles

A compact IPD project exploring how GANs can generate adversarial examples that disrupt the perception stack of autonomous vehicles. The repo includes attacks on object detection, lane detection, traffic-sign recognition, and sensor-based vision models.
It focuses on how small, GAN-crafted perturbations can mislead self-driving systems — from spoofed signs to manipulated road scenes — and documents the implementations, training flow, experiments, and evaluation results.

🔍 Highlights

GAN-based adversarial attack pipelines built specifically for AV perception models

Experiments on object detection, lane detection, and traffic-sign classifiers

Attack evaluation against common deep-learning architectures

Clean training scripts, modular code, and reproducible results

Visualizations of adversarial samples and model failures

Designed as part of an IPD research project
